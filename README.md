# JurisAlunans.github.io

The small public website behind Fruit Dungeon's Google Play listing,
published by GitHub Pages at <https://jurisalunans.github.io/>.

- `fruit-dungeon/privacy.md`: the game's privacy policy, at
  <https://jurisalunans.github.io/fruit-dungeon/privacy/>. Its source is
  `docs/privacy-policy.md` in the game's repository: change it there,
  then copy it here (keeping the front matter at the top).
- `app-ads.txt` (once there's an AdMob account): the line AdMob gives,
  at the site's root, where advertisers look for it.
